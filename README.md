# Automação de Infraestrutura Linux

## Descrição

Este projeto tem como objetivo automatizar a configuração inicial de ambientes Linux por meio de um script de provisionamento.

O script será responsável pela criação e configuração automática de usuários, grupos, diretórios e permissões de acesso, padronizando a estrutura do ambiente e reduzindo a necessidade de configurações manuais.

Após o desenvolvimento, o script será disponibilizado neste repositório do GitHub, permitindo seu versionamento, reutilização e manutenção.

Dessa forma, sempre que uma nova máquina virtual Linux for provisionada, bastará executar o script para preparar o ambiente de acordo com as configurações definidas no projeto.

## Tecnologias e conhecimentos

- **Sistema operacional:** Linux
- **Automação:** Shell Script (Bash)
- **Versionamento:** Git
- **Repositório:** GitHub
- **Área:** Infraestrutura / DevOps

**Nível:** Intermediário
